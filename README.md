# 新潟シーバス LURE SELECTOR（オフラインPWA）

スマホのホーム画面に追加して、圏外でも使えるようにするための一式です。

## ファイル
| ファイル | 中身 |
|---|---|
| index.html | 画面とスタイル |
| data.js | **データ（ルアー・地形・カラー・適性点）。編集するのはここだけ** |
| app.js | 判定ロジック |
| manifest.webmanifest | アプリ名・アイコンの設定 |
| sw.js | オフライン用のキャッシュ |
| icon-192 / 512 / 180.png | アイコン |

## スマホで使うまで（GitHub Pagesの場合）
1. GitHubで新しいリポジトリを作る（Public）
2. この8ファイルをすべてアップロード（フォルダを作らず、直下に置く）
3. Settings → Pages → Branch を main / root にして Save
4. 数分後に出る `https://ユーザー名.github.io/リポジトリ名/` をスマホで開く
5. iPhone：共有ボタン →「ホーム画面に追加」／Android：メニュー →「アプリをインストール」
6. 一度開いたあと、機内モードにして起動できれば、オフライン動作の確認完了

※ PWAとして動かすにはhttpsが必要です。ファイルをそのままスマホに置くだけでは、オフラインのホーム画面アプリになりません。Macで動かすだけなら、index.htmlをブラウザで開けば使えます（その場合sw.jsは働きません）。

## データの直し方（data.js）
- 適性点はすべて -3〜+3。数字が大きいほど、その条件に合う
- ルアーを足す：LURES に1行足す。`fl`（フィールド5つ）`t l f dp w b g` の並び順は、ファイル上部のコメントと同じ
- ポイントを足す：STRUCT のフィールド名の中に、`{n:地形名, dir:投げる方向, course:通すコース, drift:流し方, need:[[配列名, 番号, 重み]]}` を足す
- カラーを足す：COLOR_FAM に系統を足し、ルアーの `fam` で指す
- 直したら、sw.js の `lure-selector-v1` を `-v2` に変える（古いキャッシュを捨てるため）

## 注意
ルアーのレンジや重さはスペックですが、適性点・キャスト方向・流し方・反応がない時の一手は、一般的な使い方からの目安です。釣果で裏付けたものではありません。実釣に合わせて data.js を直していく前提のデータです。
